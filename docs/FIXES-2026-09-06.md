## Семантика и границы проверки

`route.ack` подтверждает сохранение bridge, а не выполнение роботом. Текст UI отражает именно это. Потеря соединения/таймаут означает отсутствие подтверждения; автоматического повторного запуска команды нет. Контроллер не переигрывает старые runtime-команды при собственном перезапуске. Журнал runtime-команд сохраняет историю; автоматическая ротация не добавлена.

Для нестандартного адреса интерфейса задайте `BRIDGE_ALLOWED_ORIGINS` списком точных Origin через запятую (например `http://127.0.0.1:5173,http://localhost:5173`). По умолчанию разрешены localhost/127.0.0.1 на портах 5173, 4173 и 8080. Клиенты без Origin сохранены для локальных CLI/контроллера; это не система авторизации для публичного сервиса.
