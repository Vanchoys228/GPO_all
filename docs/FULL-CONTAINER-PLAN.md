# Полностью контейнерный запуск и просмотр Webots

**Goal:** Запуск всех серверных процессов, Webots и контроллера через Docker Compose; камера и вид симуляции доступны пользователю в браузере.

**Architecture:** Шесть сервисов: frontend, planning, route, telemetry, gateway, simulator. Gateway и simulator обмениваются файлами в отдельном volume. База миссий и журнал gateway имеют собственные volumes. Команды идут через существующий сервисный слой; изображение сцены поступает через Webots streaming.

**Tech Stack:** Docker Compose, Linux Webots с закреплённой версией, Xvfb, C/GCC, Node.js, React, nginx. Выполнение лично, без субагентов, по указанию пользователя.
